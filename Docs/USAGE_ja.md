# Fast Curvature Baker 使い方ガイド

**Fast Curvature Baker** は、Unity エディタ上で 3D メッシュの曲率テクスチャ（Curvature Map）を GPU 高速計算によって生成するツールです。  
エッジの摩耗表現、溝の汚れ・陰影マスク、なだらかな曲面の陰影強調テクスチャをワンクリックで手軽に作成できます。

## 起動方法

Unity 上部メニューの **`dennokoworks` > `Fast Curvature Baker`** を選択するとウィンドウが開きます。

## 各部機能の解説

### 1. トップバー（ヘッダー）

- **タイトル**: `Fast Curvature Baker`
- **バージョン表示**: 現在のバージョン（例: `v1.0.0`）が表示されます。起動時に最新版の有無を自動確認します。
  - `更新あり <最新版>`: 新しいバージョンがリリースされている場合に表示されます。
  - `最新版を取得できません`: 通信エラー等で取得できなかった場合に表示されます。
- **再確認ボタン (`↻`)**: 最新バージョンの確認を手動で再試行します。
- **言語切り替えボタン (`[EN] / [JA]`)**: UI の表示言語を日本語と英語でワンクリック切り替えできます（設定は記憶されます）。

---

### 2. 対象オブジェクト (Target Objects)

ベイク対象とするメッシュ（`MeshRenderer` または `SkinnedMeshRenderer` を含む GameObject）を指定します。

- **`選択中を追加`**: Hierarchy や Scene 上で選択している GameObject を一覧に追加します。
- **`クリア`**: 登録されたターゲットを全消去します。
- **ドラッグ＆ドロップエリア**: Project や Hierarchy から GameObject を直接ドラッグ＆ドロップして追加できます。
- **オブジェクト一覧**: 登録されている GameObject が表示されます。右側の **`×`** ボタンで個別削除が可能です。

---

### 3. ベイク基本設定 (Bake Settings)

| 設定項目 | 説明 | 増減・切替による変化 |
|---|---|---|
| **ベイクモード**<br>`(Bake Mode)` | 出力するテクスチャの種類を選択します。<br>・**Default**: 符号付き曲率（平坦=0.5、凸=白、凹=黒）<br>・**Convex**: 凸エッジのみ抽出（エッジの摩耗・剥げ・ハイライト用）<br>・**Concave**: 凹部・溝のみ抽出（埃・汚れ・陰影マスク用） | 用途に応じた白黒マスクや全体曲率マップを切り替えます。 |
| **解像度**<br>`(Resolution)` | 出力テクスチャのピクセル解像度（256 〜 4096）を指定します。 | **▲増やす**: エッジがシャープになり細部が鮮明になりますが、ベイク時間とメモリが増加します。<br>**▼減らす**: 高速化・小容量化しますが、解像度が粗くなります。 |
| **UVチャンネル**<br>`(UV Channel)` | ベイクに使用するメッシュの UV チャンネル（UV0 〜 UV7）を選択します。 | 通常はメインテクスチャ用の `UV0` を使用します。 |
| **品質**<br>`(Quality)` | 半径あたりのサンプリング点数（Draft: 4点, Standard: 6点, High: 8点, Ultra: 12点）を指定します。 | **▲上げる**: ノイズが抑えられ精度が向上しますが計算時間が増加します。<br>**▼下げる**: プレビューや調整時の高速チェックに適します。 |
| **スーパーサンプリング 2x**<br>`(Supersample 2x)` | 内部で2倍解像度で計算し、平均化して出力します（解像度 4096 時は自動無効）。 | **ON**: UV 境界や細線のエイリアシング（ジャギー）を大幅に軽減します。<br>**OFF**: ベイク時間を短縮します。 |

---

### 4. ハードエッジ (エッジ検出)

法線が分割されている角（ハードエッジ・ポリゴンの明確な折り目）の検出設定です。

| 設定項目 | 説明 | 増減による変化 |
|---|---|---|
| **エッジ幅 (m)**<br>`(Edge Width)` | ハードエッジから曲率として検出するワールド空間の幅（メートル単位）です。 | **▲増やす**: 角の摩耗線が太く広がります。<br>**▼減らす**: 金属の硬質な角のような非常に細くシャープなラインになります。 |
| **エッジ強度**<br>`(Edge Strength)` | ハードエッジの曲率倍率です。値 1.0 で 90 度の直角が最大輝度に達します。 | **▲増やす**: 緩い角度の折り目でも際立ってコントラストが強くなります。<br>**▼減らす**: 影響が弱まり、0.0 でハードエッジ検出を無効化します。 |

---

### 5. 曲面設定 (曲面検出)

なだらかなスムース面の曲率検出設定です。

| 設定項目 | 説明 | 増減による変化 |
|---|---|---|
| **曲面計測半径 (m)**<br>`(Radius)` | 曲率を計算するために探索するサンプリング球の半径（メートル単位）です。 | **▲増やす**: 大きなうねりや緩やかな曲面を捉え、滑らかな大域グラデーションになります。<br>**▼減らす**: 細かなモールドや微小な凹凸に敏感に反応します。 |
| **曲面強度**<br>`(Strength)` | スムース面の曲率倍率です。半径が Radius と等しい球面の曲率が値 1.0 で最大輝度に達します。 | **▲増やす**: なだらかな曲面でも白黒のメリハリが強くなります。<br>**▼減らす**: 階調がマイルドで淡くなります。 |
| **計算ソース**<br>`(Source)` | 曲率計算に用いる法線シグナルを選択します。<br>・**ShadingNormals**: 頂点法線（滑らかな陰影）に追従<br>・**Geometry**: 実際のポリゴン面法線（面の折り目を直接計測） | **ShadingNormals**: ローポリでも陰影通りの綺麗なグラデーションが得られます。<br>**Geometry**: ハイポリやハードサーフェスでポリゴンの折り目を拾いたい場合に適します。 |

---

### 6. 詳細設定 (Advanced)

クリックして折りたたみを展開すると、高度なパラメータを調整できます。

| 設定項目 | 説明 | 切替・増減による変化 |
|---|---|---|
| **同一接続パーツのみ**<br>`(Same Part Only)` | テクセルと同一の接続されたメッシュパーツ（連結成分）のみからサンプルを取得します。 | **ON**: 肌の上に衣服が重なっているような分離パーツ間の不要な曲率干渉を防ぎます。<br>**OFF**: 近接するパーツ同士の隙間も一体として凹凸判定します。 |
| **法線拒絶しきい値**<br>`(Normal Rejection)` | テクセル法線と反対方向（裏面など）を向いている近接面を除外する内積しきい値です（以降 +0.25 の範囲で重みが復帰）。 | **▲増やす**: 薄い板の裏表などの干渉を厳格に防ぎます。<br>**▼減らす**: 急峻な溝の谷底でも確実に曲率を検出します。 |
| **ブラー反復回数**<br>`(Blur Passes)` | ベイク後に適用する 3x3 ガウシアンブラーの反復回数（0 〜 16 回）です。 | **▲増やす**: メッシュの細かなノイズを平滑化します（エッジはやや甘くなります）。<br>**▼減らす**: 元のシャープな結果を保ちます（0 で無効）。 |
| **ピクセル拡張幅 (px)**<br>`(Dilation)` | UV アイランド境界からテクスチャ結果を外側へ何ピクセル引き伸ばすかを指定します。 | **▲増やす**: ミップマップ生成時や遠景表示時の黒い継ぎ目（シーム）を防ぎます。<br>**▼減らす**: UV アイランド間の隙間が狭い場合の侵食を防ぎます。 |

---

### 7. 出力設定 (Output Settings)

- **同名ファイルを上書き保存する (`Overwrite Existing Files`)**:
  - **OFF（デフォルト）**: 同名の既存ファイルがある場合、ファイル名末尾に `スペース + 連番`（例: `Model_Curvature 1.png`, `Model_Curvature 2.png`）を自動付与して別名保存します。
  - **ON**: 既存のファイルを上書き保存します。
- **保存先パス**:
  - マテリアルにベーステクスチャが存在する場合: `<ベーステクスチャのフォルダ>/BakedCurvature/`
  - テクスチャが存在しない場合: `Assets/BakedCurvature/`

---

### 8. アクションボタン & ステータスバー

- **`曲率テクスチャをベイク`**: ベイク処理を開始します。実行中は進捗バーが表示され、途中でキャンセルも可能です。
- **`設定を初期値にリセット`**: 全ての設定パラメータを推奨デフォルト値に戻します。
- **ステータスバー**: 画面最下部に「準備完了 (`Ready`)」「処理中 (`Baking...`)」「保存完了」「エラー内容」等のメッセージが表示されます。

## 主な活用例

1. **アバターや衣装のエッジ摩耗・傷表現**
   - モードを `Convex` に設定し、`Edge Width` を小さめ（`0.002`〜`0.005`）に設定してベイク。
   - 出力されたテクスチャを lilToon や Poiyomi のリムライト・ラフネスマスク・デカールマスク等に割り当てることで、金属や革製品の角が擦れた表現をリアルに再現できます。

2. **溝やシワの汚れ・陰影マスク**
   - モードを `Concave` に設定してベイク。
   - 服のシワの谷間やパーツの結合部に溜まる埃・陰影としてシェーダーに乗算合成できます。

3. **Substance Painter や 3D ペイントソフトへの持ち込み**
   - モードを `Default` に設定してベイク。
   - 他ツールでのスマートマテリアルやジェネレーター用の曲率マップとしてそのまま利用できます。
